# 🛠️ Toolbox

A collection of simple, fast, and useful online tools for everyday tasks — all in one place.

Toolbox brings together PDF utilities, image tools, text tools, generators, calculators, productivity tools, finance utilities, and media tools into a single, easy-to-use web application.

## 📄 PDF & Document Tools

Toolbox provides a dedicated collection of tools for working with PDFs and documents.

### PDF Utilities

- Merge PDFs
- Split PDFs
- Extract PDF Pages
- Rotate PDF Pages
- Reorder PDF Pages
- Select PDF Pages
- Preview PDF Pages

### Document Conversion

- PDF to Word
- Word to PDF
- PDF to Excel
- Excel to PDF

PDF pages can be previewed visually, making it easier to select and manage the exact pages required before processing.
