About Toolbox

Simple tools for everyday tasks. No account is required.

How we handle data

Toolbox is designed so you can finish a small job without creating a profile. We do not require login, and we do not maintain a server-side history of your inputs.

Runs in your browser

  • Text, JSON, encoding, JWT, hash, and code utilities — inputs stay on your device.
  • Password, UUID, random, color, gradient, and favicon generators — generated values stay local.
  • Calculators and converters — values are calculated locally.
  • Typing, timers, lists, notes, habits, favorites, recent tools, and finance planners — selected state uses localStorage only where useful.
  • Image Color Picker and Audio Format Information — selected files stay in your browser.

Processed on the Toolbox server

These tools upload input so Python can create a result for the current request. Inputs are validated, are never put in a public upload directory, and are not retained as permanent URLs.

  • QR Code and Barcode generators
  • PDF merge, real-page preview, split, compress, page organization, metadata, encryption, inspection, image export, and image-to-PDF tools
  • PDF-to-DOCX/XLSX/PPTX and optional LibreOffice-backed Word/Excel/PowerPoint-to-PDF conversions
  • Image background removal, compression, resizing, conversion, crop, rotate, flip, metadata stripping, and optimization
  • GIF Maker

External provider

Text to Speech uses gTTS, which sends submitted text to Google to synthesize audio. Do not enter confidential text in that tool. Toolbox does not retain the text after the response.

Local preferences and technical logs

Favorites, recent tool slugs, theme preference, expenses, budgets, tasks, notes, and habits are browser-local. Clearing site data removes them. Optional analytics and advertising integrations are disabled by default; analytics events never include private tool inputs or files.

Server logs may record route names and technical failures for operations and security. The application does not intentionally log uploaded content, original filenames, passwords, generated secrets, finance data, preview images, or document text. Temporary Office conversion folders are removed after the request, including failures.
